# 中文说明

本仓库整理了儿童脑肿瘤项目的公共代码：使用预先提取的 WSI patch embeddings，
把同一患者的多张切片合成一个 bag，经过 gated-attention MIL 后预测类别。

主要支持直接二分类、六分类、十分类，原 B/C/D 三组层级模型，以及严格的六到十分类。
六组为 `{C1,C2,C3}`、`{C4,C6,C8}`、`{C5}`、`{C7}`、`{C9}`、`{C10}`。
第二阶段只细分前两组，不能改变第一阶段已经选定的大类。

当前信息融合版本的神经网络只学习图像。年龄、位置和 IHC 在图像不确定时修正概率；
IHC 统计量只由训练集估计，温度和权重只由内部验证集选择。四种信息设置共享同一套
图像模型。原 B/C/D 配置中的年龄、位置则保留直接参与网络训练的方式，两者须区分。

项目包含 fixed 25 epochs、early stopping 和多种训练改进配置。运行顺序为串行。
详细安装、命令和数据格式见[主 README](../README.md)。纯合成数据示例可以独立运行，
示例输出只用于验证代码，不能作为正式实验成绩。

**公开仓库不包含团队病人数据。** 真实病例信息、原始切片、embeddings、IHC 记录、
分折名单、训练权重、拟合后的证据统计、逐病例预测及内部报告均保留在本地。
所有使用真实数据生成的运行产物也应保存在 Git 忽略的目录中。
