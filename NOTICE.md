# Release scope and attribution

This repository contains a curated public version of the PBT research code.
It does not distribute the team's dataset, pretrained foundation-model weights,
private fitted models, or clinical reports.

No repository-wide license is declared in this initial release. Public
visibility should not be interpreted as a separate license grant. Dependencies
and upstream projects retain their own licenses and terms; no third-party model
weights or MAMMOTH reference source are vendored here. Method attribution is
provided in [references](docs/references.md).

The implementation is research software, not a clinically validated diagnostic
system. Clinical cue mappings and evidence thresholds are experimental choices.
